# Futuristic Cloud & DevOps Portfolio 2026
A production-ready, immersive portfolio built with Next.js 15, React 19, Three.js, and Framer Motion.

## Features
- **3D Infrastructure Hero**: Vertex-lit mesh representing global cloud networks.
- **Interactive Terminal**: Functional CLI for recruiters.
- **CI/CD Pipeline Visualization**: Animated workflows.
- **Glassmorphism UI**: Premium SaaS aesthetic.
- **Performance Optimized**: Built for Vercel and high Lighthouse scores.

## Getting Started
1. `npm install`
2. `npm run dev`
3. Open `http://localhost:3000`

## Tech Stack
- Next.js 15 (App Router)
- React 19
- Three.js / React Three Fiber
- Framer Motion / GSAP
- Tailwind CSS / Shadcn UI
- Lucide React (Icons)
